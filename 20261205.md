## Übung (Secure Download)
Shell script: 

```bash
#!/bin/bash
 
HomeDir=$(pwd)
 
TempDir=$(mktemp -d)
 
cd "$TempDir"
 
curl -O "https://the.earth.li/~sgtatham/putty/latest/w64/sha512sums"
 
grep "w64/putty.zip" sha512sums > line.txt
 
cut -d ' ' -f1 line.txt | tr -d '[:space:]' > hash.txt
 
openssl dgst -sha512 "$HomeDir/putty.zip" \
| cut -d '=' -f2 \
| tr -d '[:space:]' > localHash.txt
 
if cmp -s localHash.txt hash.txt
then
    echo "HASH OK"
else
    echo "HASH NICHT OK"
fi
```
