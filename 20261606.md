## Theorie

```bash
# !/bin/bash
counter=1

while ((counter <= 10))
do
    echo $counter
    ((counter++))
done
```

Erklärung:\
Die Variable counter wird mit 1 initialisiert.
Die Schleife läuft, solange counter <= 10 gilt.
echo $counter gibt den aktuellen Wert aus.
((counter++)) erhöht den Wert um 1.

Alternative Schreibweise

```bash
while [ $counter -le 10 ]
```

-le -> less or equal (≤)


### For-Schleife über eine Liste

```bash
data="1 2 3 4 5 6 7"

for d in $data
do
    echo $d
done
```

Erklärung:\
Die Variable data enthält mehrere Werte, getrennt durch Leerzeichen.
Die for-Schleife durchläuft jedes Element der Liste.
Der aktuelle Wert wird in der Variablen d gespeichert.


### Kommandozeilenargumente verarbeiten

```bash
for arg in $@
do
    echo $arg
done
```

Erklärung: $@ enthält alle beim Programmaufruf übergebenen Argumente.

### Brace Expansion

```bash
for value in {20..25}
do
    echo $value
done
```
Erklärung
Die Bash erzeugt automatisch eine Zahlenfolge.

Brace Expansion: {20..25} -> 20 21 22 23 24 25

### Internal Field Separator (IFS)

```bash
mylist="hallo welt,hello world,guten tag;ni hao"

IFS=",;"
for el in $mylist
do
    echo $el
done
```
Erklärung

IFS (Internal Field Separator) bestimmt, anhand welcher Zeichen Bash einen String in einzelne Felder aufteilt.

Hier werden zwei Trennzeichen definiert:
```bash
IFS=",;"
```
Trennung erfolgt bei:

Komma ,
Semikolon ;
